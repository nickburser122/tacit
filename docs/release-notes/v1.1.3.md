Stable release. Release build, signed outside GitHub.
- Fixed: a snippet with an unusable date format such as {date:today is dd}, or one that needs a time zone, crashed Tacit when you ran it; the placeholder now stays as typed
- Fixed: a quicklink date format that needs a time zone crashed when opened; it now falls back to the ISO date and the editor refuses it
- Fixed: a failure in the encrypted clipboard store could end the app from the background clipboard thread; the history now simply isn't saved and nothing is written unencrypted
- Fixed: a backup that held a setting of the wrong type could make Tacit crash on every start; settings now fall back to their defaults
- Fixed: a damaged backup could apply half of itself before failing; it now changes nothing unless the whole file is readable
- Fixed: Open folder on a file stored on an SD card or USB drive opened the phone's main storage instead of that folder
- Fixed: {clipboard} in a snippet was empty unless clipboard history was on; it now reads what is on the clipboard when you run the snippet
- Fixed: the calculator could stall or crash on very long input; input over 400 characters is ignored
- Changed: when a row, menu action or folder can't be opened, Tacit now says so instead of doing nothing
- Note: installs over 1.1.2 in place (same signing key)
- Tested: emulators Android 14, 15, 16; not tested on a phone
